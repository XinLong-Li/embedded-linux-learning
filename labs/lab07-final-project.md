# Lab 7：综合项目

> **目标：** 独立完成一个嵌入式 Linux 综合项目，串联学过的所有知识
>
> **时间：** 2-4 周

---

## 项目选题

### 🟢 入门级：智能传感器采集器

**硬件：** STM32MP157F-DK2 + USB 摄像头（或 I2C 传感器）

**任务：**
- [ ] I2C 读取温度/湿度传感器数据（或用 M4 内核采集）
- [ ] Linux 端 daemon 程序持续记录数据到 SQLite 数据库
- [ ] Lighttpd Web 服务器显示实时数据曲线
- [ ] 数据达到阈值时，M4 控制 LED 闪烁报警

**串联技能：** I2C驱动 → 用户空间编程 → 网络应用 → M4实时控制

---

### 🟡 进阶级：远程视频流边缘设备

**硬件：** STM32MP157F-DK2 + USB 摄像头

**任务：**
- [ ] V4L2 捕获 USB 摄像头图像
- [ ] 使用硬件编码（如果有）做 JPEG/MJPEG 压缩
- [ ] 通过 RTSP/HTTP 推流到局域网
- [ ] GPIO 控制红外补光灯（暗光自动开启）

**串联技能：** V4L2框架 → 视频编解码 → 网络流媒体 → GPIO控制

---

### 🔴 挑战级：小型 ROS2 机器人控制器

**硬件：** STM32MP157F-DK2 + 电机驱动板 + IMU

**任务：**
- [ ] A7 核运行 ROS2 Humble（交叉编译或 Docker）
- [ ] M4 核做电机 PID 控制和编码器读取
- [ ] A7 ↔ M4 通过 OpenAMP 实时交换控制指令和传感器数据
- [ ] WiFi 连接后，PC 端 RViz 可视化机器人状态

**串联技能：** ROS2系统 → AMP通信 → 实时控制 → 网络通信

---

## 项目开发流程建议

```
Week 1: 需求分析和架构设计
  ├── 确定软硬件需求
  ├── 画出系统架构图
  └── 确定关键接口(A7↔M4、GPIO、I2C等)

Week 2: 分模块开发
  ├── 先让 M4 独立工作(LED、传感器)
  ├── 再让 Linux 独立工作(数据库、Web)
  └── 最后打通 Linux ↔ M4 通信

Week 3: 集成测试
  ├── 硬件: 接线、供电、外设验证
  ├── 软件: 模块联调、异常处理
  └── 性能: 延迟测量、CPU占用、内存泄漏检查

Week 4: 文档和展示
  ├── 写出 README(架构图、接线图、启动步骤)
  ├── 录一段演示视频
  └── 整理踩坑记录和优化方案
```
